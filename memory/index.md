# Memory Index

Quick navigation for agent memory system.

## Structure
- `user/` — User preferences and context
- `lessons/` — Semantic memory (commands, errors, decisions)
- `context/` — Current working context
- `projects/` — Per-project memory

## Usage
- Read relevant files before important tasks
- Write key learnings to appropriate category
- Update preferences when user indicates changes

## Principles
- Markdown as source of truth
- Separate by function
- Write durable facts to `lessons/`
- Keep user preferences in `user/`
- Daily context in `context/`
