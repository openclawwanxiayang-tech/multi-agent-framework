# SealChat 汉金斯克导出整理

## 目录说明

- `raw/`：原始导出（尽量少加工）
- `processed/`：结构化/去重后的JSON
- `readable/`：面向阅读的Markdown版本
- `debug/`：调试中间文件
- `screenshots/`：过程截图

## 推荐读取顺序

1. `processed/hanjinsk-chat-export.complete.json`（完整、去重、API拉取）
2. `processed/hanjinsk-chat-export.trpg.v2.json`（账号-角色映射增强）
3. `readable/hanjinsk-reader-friendly-v2.md`（可读性最佳）
